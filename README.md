# Dev Notebook

Personal knowledge base for software setup, development notes, technical decisions, and lessons learned.

## Structure

- `00-inbox/` — Quick capture, chưa phân loại
- `01-guides/` — How-to guides
- `02-setup/` — Environment & project setup
- `03-decisions/` — Architecture Decision Records (ADR)
- `04-experience/` — Troubleshooting, tips, lessons learned
- `05-resources/` — Books, courses, websites, cheatsheets
- `06-archive/` — Old or inactive notes
- `_templates/` — Note templates
- `_assets/` — Images and attachments

## Usage

1. Ghi nhanh vào `00-inbox/`
2. Phân loại vào đúng thư mục
3. Thêm tag và liên kết `[[...]]`
4. Commit Git thường xuyên
