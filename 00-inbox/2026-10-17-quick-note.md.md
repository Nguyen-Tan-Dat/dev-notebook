# Quick Note

1. Có gì mới → ghi nhanh vào 00-inbox/
2. Cuối ngày:
   - Mở từng file trong inbox
   - Quyết định nó thuộc loại nào:
     • How-to  → 01-guides/
     • Setup   → 02-setup/
     • Decision→ 03-decisions/
     • Lỗi/tip → 04-experience/
     • Link    → 05-resources/
   - Chèn template tương ứng (nếu chưa có)
   - Điền nội dung
   - Thêm tag + link [[...]]
3. Cập nhật INDEX.md nếu là chủ đề mới
4. git add . && git commit -m "..." && git push
